# OHR-0004 Add & Import Employee

## User Story

***

Sebagai HR Admin, saya ingin menginput data karyawan secara manual maupun bulk upload via CSV/Excel agar pendaftaran karyawan baru dapat dilakukan dengan mudah dan efisien.

## Pre-condition

***

* Pengguna terautentikasi sebagai System Administrator / HR Admin.
* Pengguna berada di modul PIM pada menu Employee List / Add Employee.
* Berkas sampel CSV/Excel untuk bulk upload sudah disiapkan sesuai format sistem.

## Acceptance Criteria

***

1. Input Manual: Sistem dapat menyimpan data karyawan baru yang diinput satu per satu secara manual melalui formulir penambahan karyawan.
2. Bulk Upload CSV/Excel: Sistem dapat membaca, memproses, dan mengimpor banyak data karyawan sekaligus dari berkas CSV/Excel yang diunggah.
3. Validasi Format File: Mengunggah berkas bulk upload dengan format kolom yang salah atau tidak sesuai ekstensi akan ditolak oleh sistem.
4. Validasi Data Wajib: Mengosongkan data wajib seperti nama depan atau nama belakang akan memicu pesan peringatan error.
