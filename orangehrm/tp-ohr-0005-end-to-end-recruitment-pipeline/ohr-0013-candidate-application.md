# OHR-0013 Candidate Application

## User Story

***

Sebagai **HR Admin / Recruiter / Pelamar Kerja**, saya ingin menginput data profil kandidat dan mengunggah berkas resume/CV, agar data pendaftaran kandidat tersimpan dengan aman di dalam sistem.

## Pre-condition

***

* Pengguna terautentikasi sebagai **HR Admin / Recruiter** (atau mengakses form pendaftaran kandidat).
* Pengguna berada di modul **Recruitment** pada sub-menu **Candidates** (/recruitment/viewCandidates).
* Terdapat lowongan pekerjaan (_Vacancy_) berstatus **Active** di dalam sistem (dari TC-OHR-REC-VAC-001).
* Berkas sampel resume/CV (PDF/DOCX) dan file non-standar (.exe/.zip) telah disiapkan.

## Acceptance Criteria

***

1. **Input Manual Kandidat:** Sistem dapat menginput dan menyimpan data kandidat baru secara manual beserta alamat email dan kontak yang valid.
2. **Upload Resume/CV:** Sistem dapat mengunggah dan melampirkan berkas resume/CV kandidat ke dalam profil pendaftaran.
3. **Validasi Format File Resume:** Mengunggah berkas resume dengan ekstensi/format file yang tidak didukung akan ditolak oleh sistem.
4. **Validasi Duplikasi Email Kandidat:** Menginput pendaftaran kandidat baru menggunakan alamat email yang sudah terdaftar pada lowongan yang sama akan ditolak oleh sistem.
