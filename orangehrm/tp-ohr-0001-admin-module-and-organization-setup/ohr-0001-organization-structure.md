# OHR-0001 Organization Structure

## User Story

***

Sebagai HR Admin, saya ingin membuat dan mengelola struktur unit kerja, departemen, dan lokasi kantor agar organisasi terpetakan dengan jelas.

## Pre-condition

***

* Pengguna terautentikasi sebagai System Administrator / HR Admin.
* Pengguna berada di modul Admin pada menu Organization.

## Acceptance Criteria

***

1. Unit Kerja dan Departemen: Sistem dapat menambahkan, mengubah, dan menghapus unit kerja serta departemen ke dalam struktur hierarki organisasi.
2. Lokasi Kantor: Sistem dapat menambahkan data lokasi kantor baru beserta detail alamat dan zona waktunya.
3. Validasi Input: Mengosongkan nama unit, departemen, atau lokasi kantor akan memicu pesan peringatan bahwa data wajib diisi.
4. Penghapusan Data: Menghapus unit atau lokasi yang masih memiliki keterikatan data akan menampilkan pesan konfirmasi atau pencegahan.
