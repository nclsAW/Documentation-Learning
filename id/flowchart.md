# Flowchart

## Features <a href="#features" id="features"></a>

***

1. Adding node button
   * Start
   * Process
   * Decision
   * I/O
   * End
2. Center button
3. Export PNG button

## How to <a href="#how-to" id="how-to"></a>

***

1. Klik tombol Start, Process, Decision, I/O, End button untuk menambah node sesuai standar flowchart
2. Klik dua kali pada node jenis manapun untuk menghubungkan node satu dengan yang lainnya

* Contoh:
  * Node 2 adalah tujuan setelah node start, maka node 2 akan di klik 2 kali dan dihubungkan ke node start, sehingga tanda panahnya akan mengarah ke node 2.

3. Klik Center untuk memosisikan kamera user ke posisi tengah yang sudah ditentukan.
4. Klik Export PNG untuk mengekspor canvas ke dalam PNG beserta dengan keutuhan datanya.
