# Flowchart

## Features <a href="#features" id="features"></a>

***

1. Adding node button
   * Start
   * Process
   * Decision
   * I/O
   * End
2. Center button
3. Export PNG button

## How to <a href="#how-to" id="how-to"></a>

***

1. Click the Start, Process, Decision, I/O, and End buttons to add nodes according to standard flowchart conventions.
2. Double-click any type of node to connect one node to another.

* Example:
  * Since Node 2 is the destination after the Start node, double-click Node 2 and connect it to the Start node so that the arrow points toward Node 2.

3. Click Center to position the user’s camera at the predetermined center.
4. Click Export PNG to export the canvas as a PNG file along with all its data.
