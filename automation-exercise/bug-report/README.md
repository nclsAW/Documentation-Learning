# Bug Report

## Description

***

Mulai dari halaman ini beserta seluruh sub-halaman di dalamnya, cakupan dokumentasi dikhususkan untuk rekapitulasi laporan bug/isu teknis, detail reproduksi langkah (_steps to reproduce_), serta lampiran bukti pendukung (tangkapan layar, rekaman log, dan data pengujian). Dokumen ini ditujukan sebagai portfolio dari bug report.

{% hint style="info" %}
Ada beberapa elemen yang akan disesuaikan agar informasi dari bug report tersebut tetap tersampaikan dengan baik seperti yang saya kerjakan dalam jira untuk mmebuat task tersebut.
{% endhint %}
